# KPilot Android

[English](README.md) | [简体中文](README.zh-CN.md)

KPilot 是一款用于已越狱 Kindle 的 Android 辅助应用，通过 SSH 连接 Kindle，主要功能包括：

- 传输 EPUB、PDF、MOBI、AZW3 和 TXT 文件
- 下载并查看 `My Clippings.txt` 摘抄
- 浏览 Kindle 书库、封面和阅读进度，离线搜索并查看单本书摘抄
- 随机回顾历史摘抄，支持收藏、隐藏和每日回顾计数
- 生词本复习：按 iOS 相同的学习步骤和 SM-2 风格间隔安排新词/复习，可补充本地释义
- 终端风格的“每日收藏”桌面小组件，使用 Terminus 控制台字体
- 离线编辑批注，并反向写入 Kindle 的 AZW3、MOBI、KFX 已有标注
- 下载并查看 Kindle 生词本
- 通过手机、硬件按键或小米穿戴设备遥控翻页
- 在 Android 本地加密保存 Kindle SSH 连接设置
- 与 iOS 一致的图标底栏，可隐藏生词本和遥控入口

Kindle 需要安装 UsbNet 或 UsbNetLite、开启 SSH，并且能够被 Android 设备访问。

## 新功能使用

书架、摘抄、生词本和遥控页使用下拉刷新。书架按三列显示书籍；右上角加号用于传书，列表图标用于查看传书状态。点击书籍查看本书摘抄。传书文件写入 `/mnt/us/documents/Downloads/Items01`（目录不存在时会自动创建）。

摘抄页和生词本顶部有“回顾”入口。摘抄回顾会优先展示较少回顾的条目并交错不同书籍，支持收藏、隐藏、下一条和 3 秒内撤销，并记录今日回顾数量。生词复习采用与 iOS 相同的学习步骤和 SM-2 风格间隔；评分后自动进入下一张卡，学习中的卡片到期后自动重新出现。生词详情中可补充本地释义，释义会参与搜索并显示在复习答案中。

设置页的“桌面小组件”可以预览“默认”“终端绿”和“终端琥珀”。终端风的西文使用 Terminus 控制台字体，小组件的中文使用朱雀仿宋。长按主屏幕即可添加 KPilot“每日收藏”小组件。小组件在本地午夜自动更换收藏摘抄，点右下角箭头可以立即切换。收藏数据保存在应用私有文件中，小组件可离线使用。

复习数据可以通过 Kindle 本机在多台手机之间同步，不需要账号或云服务。连接 Kindle 和下拉刷新时，应用会在 Kindle 端加锁，将本机数据与 `/mnt/us/kpilot/learning/state.json` 合并，然后原子替换该文件并回读校验。收藏和隐藏按字段采用最新修改；生词卡和释义按整条记录采用最新修改，时间相同时用手机标识决定；回顾次数取较大值。每日回顾数量仍只保存在各自手机。该文件不包含 SSH 密码。目前只有 Android 端使用这一同步协议，iOS 端尚未读写该文件。

设置页分为 Kindle 连接、底部导航栏、本地数据、关于和支持作者。连接页可管理多个 Kindle 配置；本地数据页可导入摘抄或生词数据库、导出资料库备份、查看缓存并清除本机数据。密码通过 Android Keystore 加密保存。

摘抄、书架、设置固定显示，只有生词本和遥控可隐藏。遥控页保留翻页、音量键和小米手环。

在标注详情中直接编辑批注，修改会自动保存到本机。点击“发送到当前 Kindle”写回设备，发送前请退出 Kindle 阅读器并回到主页。清空后发送可以删除批注，保留划线。

反向写入会校验目标标注、修改书籍 sidecar 和 `My Clippings.txt`，将原文件备份为同目录的 `.kpilot-note-backup-*.bak`。校验失败时尝试恢复；如文件已被其他程序修改，会保留外部修改和备份，并报告恢复失败。匹配不明确、格式不支持或阅读器状态不可确认时停止写入，保留本地草稿。

书库、摘抄、生词缓存和批注草稿按 Kindle 的稳定设备标识隔离。首次连接会在 Kindle 的 `/mnt/us/.kpilot/device-id` 创建或读取标识，之后 Kindle 更换 IP、或从另一台手机连接，仍然对应同一份数据；旧的按 IP/端口建立的缓存会在首次识别时自动迁移。每台手机在该标识下保留自己的本地副本，Kindle 上的回顾数据文件是多台手机之间的一致性副本。同步失败时保留本机数据并显示错误。

书架支持长按 AZW / AZW3 / MOBI / PRC 书籍并选择“修复 Kindle 封面”。应用会从书籍提取内嵌封面，生成 Kindle 书架缩略图，直接替换旧图并回读校验（不保留旧图备份）；不会修改正文、笔记、阅读进度、`cc.db` 或 `.sdr`。传入 AZW3 / MOBI 后也会自动补写封面，EPUB / PDF 暂不自动处理。Kindle 联网后可能再次覆盖封面，届时可重复修复。

长按任意书籍还可选择“从 Kindle 删除”：仅删除书籍会保留笔记和阅读进度；删除书籍和阅读记录会同时删除对应的 `.sdr` 目录。删除前会二次确认，且只接受 `/mnt/us/documents` 下受支持扩展名的书籍路径。

## 构建

使用 Android Studio 打开项目并构建 `app` 模块。

项目使用 Java 25（由 Gradle toolchain 配置）。本地检查：`./gradlew testDebugUnitTest assembleDebug lintDebug`。单元测试覆盖离线持久化、导航规则、写入匹配、双文件事务、失败恢复、回顾数据合并以及每日收藏轮换；真实 Kindle 的固件与 SSH 行为仍需实机验证。`connectedDebugAndroidTest` 会在设备上安装应用并在结束后默认卸载 APK；`gradle.properties` 已设置为保留安装，避免运行小组件测试时清除本地应用数据。

小米穿戴设备互联功能依赖小米闭源的穿戴设备互联 SDK。该 SDK 不包含在本仓库中，构建前需要自行获取，并将以下文件放入项目：

```text
app/libs/xms-wearable-lib_1.4_release.aar
```

文件的预期 SHA-256 为：

```text
9c40fd1c5409bb948523d503af71e2978ae522c35636afe7d64f474c0f6bc195
```

如果需要分发包含该 SDK 的 APK，请先确认并遵守小米适用的 SDK 条款。
